OVERVIEW
----------------------------------------------------------------
This project trains 3 machine learning models — Random Forest
(RF), Gradient Boosting (GB), and Deep Neural Network (DNN) —
across 3 different dataset pipelines, resulting in 9 total
experiments. Each model is evaluated on two tasks:

  Task A — Regression    : Predict crop yield (metric tons)
  Task B — Classification: Recommend the best crop to grow

1. merged_dataset_comparison.png
----------------------------------------------------------------
  This chart shows the performance of RF, GB, and DNN trained
  on the original merged raw dataset (4,607 rows). It contains
  6 subplots:

  Top row (Regression — Task A):
    - R² Score   : GB scores highest at 0.9455, meaning it
                   explains 94.5% of yield variation. RF is
                   close at 0.9376. DNN is lower at 0.8261.
    - RMSE       : GB has the lowest error (0.5679), confirming
                   it gives the most accurate yield predictions.
    - MAE        : GB again best (0.3866), meaning predictions
                   are off by only ~0.39 on the log scale.

  Bottom row (Classification — Task B):
    - Accuracy   : DNN leads at 94.03%, correctly identifying
                   the right crop in 94 out of 100 cases.
    - F1 Score   : DNN scores 0.9331, showing strong balance
                   between precision and recall across 72 crops.
    - Summary table: All 3 models side by side for quick view.

  Key finding: Raw merged data with GB is best for yield
  prediction. DNN is best for crop recommendation.


2. preprocessed_dataset_comparison.png
----------------------------------------------------------------
  This chart shows results after formal preprocessing steps:
  outlier removal (IQR 3x), label encoding, log transform,
  and StandardScaler normalization. Dataset size reduced from
  4,607 to 3,729 clean rows.

  Top row (Regression):
    - R² drops slightly compared to merged raw (GB: 0.9067 vs
      0.9455). This is because IQR outlier removal removes some
      extreme but real production values from training.
    - RMSE and MAE are slightly worse for the same reason.

  Bottom row (Classification):
    - DNN accuracy is 92.36%, slightly lower than on merged
      raw. The reduced dataset size (3,729 rows) means less
      data for the neural network to learn from.

  Key finding: Formal preprocessing improves data quality but
  reduces dataset size, which slightly lowers model scores.
  GB still best for regression, DNN best for classification.


3. augmented_dataset_comparison.png
----------------------------------------------------------------
  This chart shows results after data augmentation, where the
  original 4,607 rows were expanded to 50,000 rows using three
  methods: Gaussian Noise, KNN Interpolation, and Season-Aware
  Scaling. After preprocessing, the clean augmented dataset
  has 37,578 rows with 27,055 used for training.

  Top row (Regression):
    - RF improves to R²=0.9082, showing that more training
      data helps tree-based models generalize better.
    - GB and DNN also perform well (R²=0.8979, 0.8804).
    - RMSE is slightly higher than merged raw because augmented
      data introduces synthetic noise.

  Bottom row (Classification):
    - All three models show strong and consistent accuracy
      (RF: 91.99%, GB: 91.79%, DNN: 92.23%).
    - The gap between models is smaller — augmentation makes
      models more equally capable.
    - DNN classification improves over preprocessed (92.23%
      vs 92.36%), confirming more data helps DNN.

  Key finding: Augmentation most benefits RF for regression
  and helps all models generalize to unseen crop-district
  combinations. DNN gains the most from extra data.


4. master_comparison.png
----------------------------------------------------------------
  This is the final summary chart combining all 9 experiments
  across all 3 pipelines and 3 models. It allows direct visual
  comparison of how each model performs as data quality and
  size change.

  Top row (Regression metrics R², RMSE, MAE):
    - GB consistently scores high across all pipelines.
    - RF is strong on merged and augmented data.
    - DNN shows steady improvement as dataset size grows
      (augmentation helps DNN regression the most: 0.82→0.88).

  Bottom row (Classification metrics Accuracy, F1):
    - DNN leads on merged and preprocessed data.
    - On augmented data, all three models converge around 92%,
      showing augmentation reduces the advantage of any single
      model.
    - Summary table provides exact numbers for all 9 runs.

  Gold border highlights the best bar in each subplot.

  Overall conclusion: For a real deployment scenario, use
  GB for yield prediction (highest R²=0.9455) and DNN for
  crop recommendation (highest Acc=94.03%), both trained on
  the original merged dataset.
